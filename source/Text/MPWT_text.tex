\textbf{លោកស្រី ព្រមទាំងក្រុមគ្រួសារជាទីរាប់អាន!}\\

ខ្ញុំនិងភរិយា ព្រមទាំងថ្នាក់ដឹកនាំ និងមន្ត្រីរាជការនៃក្រសួងសាធារណការ និងដឹកជញ្ជូន មានសេចក្តី រន្ធត់ក្ដុកក្ដួលរំជួលចិត្តឥតឧបមាក្រោយពីបានទទួលដំណឹងថា លោក គួច លឹមហាន បុគ្គលិកផ្នែក ភូគព្ភសាស្ត្រ នៃមន្ទីរពិសោធន៍សំណង់ និងសាធារណការ នៃក្រសួងសាធារណការ និងដឹកជញ្ជូន ត្រូវជា ឧត្តមស្វាមីរបស់ លោកស្រី បានទទួលមរណភាពនៅថ្ងៃអង្គារ ១៤កើត ខែទុតិយាសាឍ ឆ្នាំមមី អដ្ឋស័ក ព.ស.២៥៧០ ត្រូវនឹងថ្ងៃទី២៨ ខែកក្កដា ឆ្នាំ២០២៦ វេលាម៉ោង ២៣:៣០នាទីយប់ ក្នុងជន្មាយុ ៣៥ឆ្នាំ ដោយគ្រោះថ្នាក់ចរាចរណ៍។\\

ស្ថិតក្នុងបរិយាកាសដ៏សែនក្រៀមក្រំនេះ យើងខ្ញុំទាំងអស់គ្នាសូមចូលរួមរំលែកទុក្ខជាមួយ លោកស្រី និងក្រុមគ្រួសារ ចំពោះការបាត់បង់ដ៏ធំធេងនូវ ឧត្តមស្វាមី ឪពុកបង្កើត កូនបង្កើត និងប្អូនបង្កើត ជាទីគោរព ស្រឡាញ់ដ៏ជ្រាលជ្រៅបំផុត និងប្រកបដោយព្រហ្មវិហារធម៌ដ៏ថ្លៃថ្លា ដែលកន្លងមក លោក គួច លឹមហាន ធ្លាប់មានគុណូបការៈខ្ពស់ចំពោះបុត្រធីតា ព្រមទាំងក្រុមគ្រួសារ ញាតិមិត្ត និងបងប្អូន។\\

ជាថ្មីម្តងទៀត ខ្ញុំនិងភរិយា ព្រមទាំងថ្នាក់ដឹកនាំ និងមន្ត្រីរាជការនៃក្រសួងសាធារណការ និងដឹកជញ្ជូន សូមលំឱនកាយឧទ្ទិសបួងសួងសូមដួងវិញ្ញាណក្ខន្ធ លោក គួច លឹមហាន បានបដិសន្ធិក្នុងសុគតិភព កុំបីឃ្លៀងឃ្លាតឡើយ។\\

សូម លោកស្រី និងក្រុមគ្រួសារ ទទួលនូវការចូលរួមរំលែកទុក្ខដ៏ក្រៀមក្រំពីយើងខ្ញុំទាំងអស់គ្នា។ឮឮ
}
